# 各子服务器的差异

Space Creator EX. 子服务器集合的简要介绍。

## 整合包侧「须臾」

使用成熟整合包开设的周目制服务器。

玩家可通过提名与投票参与下一期周目自选。  
当预设主线进度被攻克、活跃度长期低于阈值，或管理员发起结档投票通过时，当前周目将结档并轮换至新周目。

[在此处](https://docs.qq.com/sheet/DRllNandVZnhiSHpi?tab=9h89ks)通过在线表格提名整合包。  
[在此处](https://forum.hoorimanor.top/vote/)查看往届周目记录，参与投票。

## 创造养老侧「永远」

包含机械动力航空学等模组的创造模式服务器。

大建筑是此服务器的主要活动。  
部分活动，如基于航空学的载具战，周年合影等也在此处进行。  
存档长期保留且有本地/异地定时备份。  

该子服务器正在维护中。

## 怀旧向子服「旧梦」

这是基于Neoforge 1.21.1 的怀旧向长期企划，旨在用现代版本重建供类 1.7.10 的 Mod 生态，以及早年公益服的怀旧体验。
