## 准备 Java 环境

Minecraft 依赖 Java 运行，您的计算机需要正确安装 Java 环境。  
通常，这些操作将由启动器完成，但我们强烈建议完成**环境变量**的配置。这有助于后续运行其他基于 Java 的程序。  

## 登录验证相关

服务器现使用离线登录验证 + simplelogin 模组方案。  
使用离线登录/正版验证均可进入服务器。
